# 0009: Authentication

Date: 2026-11-19. Status: accepted 2026-11-22 (proposed in Phase 2).

## Decision

Does not apply. There are no accounts, no service and no users besides the author. The only credential involved is the per run CI token, which gets `permissions: contents: read` (R20). The author's GitHub sign in stays in the laptop credential store and is out of scope.

## What would change this

The tier moving to B or C, for example a hosted notebook with sign in.
